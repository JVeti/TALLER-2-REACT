# Taller 2 – Desarrollo Frontend

**Estudiante:** José Vega

**Tema:** Investigación sobre React

## Descripción

Este repositorio contiene el Taller 2 del segundo corte de la asignatura Desarrollo Frontend. El trabajo presenta una investigación sobre React, sus fundamentos, los problemas que resuelve, sus principales elementos y su importancia en la industria.

## Contenido

- ¿Qué es React?
- ¿Qué problema resuelve React?
- Principales elementos: componentes, JSX, props, estado y eventos.
- Importancia de React en la industria.
- Empresas que utilizan React.
- Conclusiones y referencias.
